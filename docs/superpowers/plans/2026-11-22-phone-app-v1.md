# Phone app v1: Mini on the phone — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner asked to "run the mini bot in my mobile now". Deliver an installable Android app, "Mini", that
floats the bot over other apps, starts Mini's Claude Code session in Termux, and lets the owner type or speak to
it and read or hear the reply, with Hide and Stop. Recording calls and messages, the phone tools and syncing with
the hub come later (Phases 2, 3 and 5 of `docs/10-build-plan.md`).

**Architecture:** A Kotlin app (`android/`, package `app.minihub.phone`). It starts Mini through Termux's
`RUN_COMMAND` service, sending a start script on standard input; the script (in Termux) fetches the Mini Bot
plugin from its public repository if it is missing, starts the plugin's runtime and Claude Code in tmux with
`LD_PRELOAD` unset and permission mode `dontAsk`, and prints one line `MINI_READY {"port":N,"token":"…"}` that comes
back to the app only, through its own pending intent. The app then talks to the runtime on `127.0.0.1` like the
hub's `mini` connector: `POST /v1/prompts`, `GET /v1/state` for the reply as it is written.

**Tech Stack:** Kotlin, Android Gradle Plugin 9.0.1 with its built-in Kotlin, Gradle 9.3.1, minSdk 33, targetSdk 36,
Android Views (no Compose), `org.json`, JUnit 4.

**Spec:** `docs/08-android-app.md`, `docs/03-security-and-permissions.md`; trial T1 results in `docs/10-build-plan.md`.

## Global Constraints

- **The owner commits.** No task commits.
- Nothing is typed into the phone with `adb input`; consent screens (permissions, Termux's own settings, Claude
  Code's trust question) are answered by the owner.
- The runtime token reaches the app only through its own pending intent, is kept in memory, and is never logged or written.
- The release APK is signed with a key kept in `local/` (ignored by git), and is not debuggable.
- Speech: Android's on-device recognizer when the phone has one; otherwise the app says so and offers typing.
- The bot can be hidden; while Mini is running, the status notification stays.
- Deviation from `docs/08`, ruled for v1: Android Views instead of Compose (a smaller app and a simpler overlay).

## Review Focus

1. **Termux not set up** (outside apps not allowed, permission not granted, Termux missing): the app says which step is missing.
2. **Mini's session stops on its own** (as the owner saw with `/exit`): the bot shows it is asleep and Start brings it back.
3. **A reply never comes**: the panel stops waiting after 3 minutes and says so.
4. **The phone restarts**: nothing starts by itself in v1; the app opens to Start.
5. **Long replies**: the panel scrolls; speech reads the first 600 characters.

### Task 1: Project, signing and the pure logic

**Files:** `android/{settings.gradle.kts, build.gradle.kts, gradle.properties, gradle/wrapper/*, app/build.gradle.kts}`,
`android/app/src/main/java/app/minihub/phone/brain/{ReadyLine.kt, ReplyTracker.kt, StartScript.kt}`,
`android/app/src/main/assets/start-mini.sh`, tests in `android/app/src/test/java/app/minihub/phone/brain/`.

**Interfaces:**
- `ReadyLine.parse(stdout: String): Result<Runtime>` with `Runtime(port: Int, token: String)`; finds the line
  `MINI_READY {...}`; otherwise the last `MINI_ERROR <text>` line, or "Mini did not start".
- `ReplyTracker.read(stateJson: String, promptId: String): Reply` with `Reply = Waiting | Partial(text) | Final(text, isError) | Asleep`.
- `start-mini.sh`: unsets `LD_PRELOAD`; clones `https://github.com/Vinith-00704/Claude-Mini-bot` into
  `~/.mini/plugin` when missing; starts tmux `-L mini` sessions `rt` (runtime, `--serve`) and `mini` (Claude Code with
  `--plugin-dir`, `-n Mini`, `--permission-mode dontAsk`, `--disallowedTools=AskUserQuestion,EnterPlanMode`) when not
  running; sets `CLAUDE_CODE_TMPDIR` inside `~/.mini`; takes Termux's wake lock; waits up to 40 s for `runtime.json`;
  prints `MINI_READY {"port":…,"token":"…"}`. `stop-mini.sh` kills both tmux sessions and releases the wake lock.
- [ ] Tests: `ReadyLineTest` (ready line found among other lines; error line; nothing), `ReplyTrackerTest`
  (other prompt's reply → Waiting; partial; final; error; `running:false` → Asleep), `StartScriptTest` (the asset
  unsets LD_PRELOAD, uses dontAsk, never echoes the token except in the MINI_READY line).

### Task 2: Termux link, runtime client, voice

**Files:** `brain/{Termux.kt, RuntimeClient.kt}`, `voice/Voice.kt`.
- `Termux.run(context, script, label, onResult)` sends `RUN_COMMAND` (bash `-s`, script on stdin, background) with a
  mutable pending intent to `TermuxResultReceiver`, which hands `stdout/stderr/exitCode/errmsg` to the waiting call.
- `RuntimeClient(runtime).ask(text, spoken): String` (prompt id) and `state(): String`, `HttpURLConnection` with a 5 s timeout.
- `Voice`: on-device `SpeechRecognizer` if `isOnDeviceRecognitionAvailable`, `TextToSpeech` for replies to spoken prompts.

### Task 3: The floating bot and its panel

**Files:** `overlay/{SpriteView.kt, Bubble.kt, Panel.kt}`, `MiniService.kt`.
- Foreground service (`specialUse`, plus `microphone` while listening) with the notification "Mini is on" and Stop.
- Bubble: the default character in the accent `#d77757`, idle bob and blink, thinking and listening states, drag to
  move, snaps to the edge, tap opens the panel.
- Panel: the last reply (scrolls), a text box, Send, a microphone button, Hide, Stop, and an "asleep" line with Start.

### Task 4: The app screen and setup checks

**Files:** `MainActivity.kt`, `res/layout/*`, `AndroidManifest.xml`.
- Checklist with a button for each missing step: Termux installed; "Run commands in Termux" permission (runtime
  request); Termux allows outside apps (detected by a failed run, with the line to add shown for the owner);
  display over other apps; microphone; notifications; battery unrestricted for Mini and for Termux.
- Start Mini / Stop Mini; Show bot.

- [ ] `./gradlew testReleaseUnitTest assembleRelease`; install with `adb install -r`.
- [ ] The owner grants the permissions and adds `allow-external-apps = true` in Termux; Start; a typed and a spoken
